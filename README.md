# xmetia-seamless

无缝隙预报业务平台（Seamless Forecast Operations Platform）。

以预报结果数据为核心，提供从临近、短期、中期到延伸期的一条连续时间线上的
预报检索、展示与分析能力：后端负责数据接入与查询，前端负责地图、时序和
多模型对比展示。

## 规划

- **后端**：预报数据接入（多模型、多时效、多成员）、按起报/时效/区域检索与切片、统计与派生量计算、REST API
- **前端**：全球/区域预报地图、逐时效时间轴、多模型对比、集合离散度与概率展示

## 规划中的目录结构

xmetia-seamless/
